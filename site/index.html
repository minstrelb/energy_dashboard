한국 전력수급 대시보드

공공데이터포털 API로 받은 5분 단위 전력수급을 매일 쌓아 만든 대시보드입니다. 계산은 이 브라우저 안에서 DuckDB가 합니다.

DuckDB 엔진을 내려받는 중…

하루의 전력수급 곡선 (5분 단위)

현재수요 = 지금 쓰고 있는 전력 / 공급능력 = 공급할 수 있는 최대치 / 최대예측수요 = 그날 예상한 최대 수요.

일별 최대수요와 최저 공급예비율

막대 = 그날의 최대수요, 선 = 그날의 가장 낮은 공급예비율. 연한 막대는 하루치가 다 모이지 않은 날입니다.

시간대별 수요

모인 모든 날의 시(0~23시)별 평균과 최대·최소. 하루 중 언제 전기를 많이 쓰는지 보입니다.

직접 SQL 써보기

표 supply: ts(시각), demand_mw(현재수요), supply_mw(공급능력), forecast_mw(최대예측수요), reserve_mw(공급예비력), reserve_pct(공급예비율 %), oper_reserve_mw(운영예비력), oper_reserve_pct(운영예비율 %)  (Ctrl/⌘ + Enter로 실행)

출처: 한국전력거래소 「오늘전력수급현황조회」(공공데이터포털 OpenAPI, 이용허락범위 제한 없음). 수요·공급능력·예비력의 단위는 MW입니다. API는 '오늘' 하루치만 제공하므로 매일 받아서 쌓은 기간만 표시됩니다.
